KIWANUKA LIVINGSTONE WEBSITE
=============================

1. Keep index.html and the images folder together.
2. Open index.html in a browser to preview the website.
3. Upload the whole folder to a static website host (for example, GitHub Pages or Netlify).
4. After you have a real domain, add a canonical URL and update the Open Graph URL/image metadata.
5. Submit the live website and sitemap.xml through Google Search Console.

Important:
- Gallery designs are labelled as concept/illustrative artwork. Do not present them as proof of real TV/radio appearances or parliamentary service.
- The phone number is included as a contact link. Publish it only with Kiwanuka's permission.
- Google does not use the meta keywords tag for ranking; useful content, mobile usability, links and indexing matter more.
